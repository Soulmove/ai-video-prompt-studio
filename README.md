# 镜序 · AI短剧提示词工作台

浏览器本地优先的中文创作工具：选择人物、影像质感、场景与摄影，填写分镜时间和动作，整理可复制提示词。

## 使用

线上版本以交付消息中的实际发布链接为准。新建站点保持仅本人可访问。

本地运行需要 Node.js 20 或以上，无需安装依赖：

```powershell
node server.mjs
```

打开 `http://127.0.0.1:4173`。必须通过HTTP运行，直接双击HTML文件不能可靠加载模块和使用本地存储。

```powershell
npm test
node --check dist/app.mjs
```

## 数据与边界

项目保存在当前浏览器的 IndexedDB；偏好和角色模板保存在 localStorage。没有账号同步，也不会自动向生成平台上传素材。清理浏览器数据可能清除本地项目，应定期导出完整JSON。参考文件单个上限8MB；完整备份可以携带文件数据。

上传素材仅提供本地预览和人工用途标记，不执行图像或音频分析。二维示意和模板小图是构图示意，不是已生成的电影画面。对白时长属于文本估计，需通过实际录音核验。

目前目标平台使用通用自然语言输出，未针对各平台版本进行生成实测。8K、帧率、画幅和秒数是创作/交付目标，真实能力由对应平台入口决定。现已提供个人 Google API 的结构化方案填写；完整自由文本英文翻译及真实图片/视频生成尚未接入。英文模式保留人物、剧情和台词等用户自由文本原文。

拆合镜会预览处理方式；已有对白或细分时间段时，要求先手动安排内容归属，防止静默损失。跨镜检查只核对已结构化声明的事实，不能保证实际生成画面不穿帮。

## 工程结构

`dist/index.html` 为静态入口，`dist/style.css` 为界面样式，`dist/catalog.mjs` 为词库、模板和来源，`dist/model.mjs` 为时间、继承、检查和输出，`dist/storage.mjs` 为本地存储，`dist/app.mjs` 为交互界面。无外部CDN、字体或运行时依赖。

`.openai/hosting.json` 保存站点身份，不包含凭据。`worker/` 提供同源服务，`npm run build` 生成单个 Worker ESM 与内嵌静态资源。源代码包不包含发布凭据、个人项目或浏览器存储。

## V1.1 更新

## V1.2 更新
添加/编辑分镜新增空列表“去添加”引导：场景、说话人物、出场人物、道具和商品参考素材均可跳转创建并返回选择位置。新增94套模块组合及16套五官组合，组合先预览、可只填空白，并尊重角色锁定。文本属性支持下拉参考示例和自由输入；短属性与秒数按内容收窄。预设为本工作台整理的创作起点，不替代用户判断。

### V1.2 滚动修复
快捷动作只更新现有输入框与实时输出，不重建编辑区；普通文本提交不再重建页面，编辑器滚动恢复取消平滑动画，减少选项点击时的上下跳动。

## V1.3 更新
导航按人物、质感、场景、表演、添加/编辑运镜、摄影预选排序；角色与场景显示数量。镜头均可独立收起，移除灵感起点条。镜头名、秒数与场景并排；长文本默认两行，支持展开收回。摄影页保存命名预选，跨项目选用，每镜保存独立副本。项目列表支持逐个删除和一键清空，均须确认，并阻止旧自动保存恢复已删草稿。画面要求新增20项可多选负面提示词及自定义；画幅、分辨率、帧率、时长直接位于可复制提示词首行，单镜使用本镜时长，静帧仅输出画幅与分辨率。

## V1.4 创作体验更新
新增电影氛围创作首页、继续上次草稿、想法/模板/商品广告三个起点与内置故事卡。作品灵感馆保留静态未开放展示位，不接入外部内容。工作台新增一句话创作起点、四步进度、独立固定底栏和推荐组合卡；细节设置按需展开，分镜可直接应用16套内置摄影方案。刷新和返回首页保留项目与编辑位置。数据格式版本不变，兼容原项目；从零开始仍输出空白。首页视觉素材和完整生成提示词见 ASSETS.md。

## V1.5 AI填写与视频创作
用户可在服务连接页使用自己的 Google API Key，默认 Gemini 4 Hydrogen，密钥只保留当前页面内存。AI根据想法生成结构化方案，可自动填入人物、质感、场景与分镜；已有内容时另存新项目，用户可继续修改。可关闭自动填入，预览后选择需要的部分。

新增视频创作区：全文/单镜/自定义提示词、文生视频/参考图/首尾帧准备、生成计划快照、外部视频链接导入与播放器。Muse真实生成尚未接入；不模拟提交、进度或生成结果。
